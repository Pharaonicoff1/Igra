# assets

Растровые ассеты игры. Всё остальное в «Orbit Jumper» рисуется процедурно
на Canvas — сюда попадает только то, что нарисовать кодом нельзя.

## logo.png

Логотип главного меню: две строки «ORBIT» / «JUMPER», прозрачный фон.

Требования:
- прозрачный фон (PNG-24 с альфа-каналом);
- поля вокруг надписи сведены к минимуму — отступы в меню задаются кодом,
  лишняя прозрачная рамка внутри файла сместит логотип и собьёт вёрстку;
- ширина не меньше 1024px. Логотип рисуется во всю ширину контейнера меню
  (до 420 CSS-px), а на экранах с devicePixelRatio 3 это уже 1260 реальных
  пикселей — файл меньшего размера будет мылить.

Пропорции файла код читает сам (naturalWidth/naturalHeight) и сохраняет их
при вписывании, поэтому конкретное соотношение сторон не задано жёстко.
Если файла нет, игра запускается штатно — место под логотип резервируется,
но остаётся пустым.
